# Shiridi Sai Nilayam Apartment Management

Mobile-first Apartment Management System.

## Stack
- React 18
- TailwindCSS
- Trickle Database

## Structure
- `index.html`: Login Page with automatic Connectivity Health Check diagnostics.
- `admin.html`: Admin Dashboard (Maintenance Incharge) - includes Water, Expenses, Bills, and Payments modules (Flats management removed from UI but preserved in DB)
- `user.html`: User Dashboard (Owners/Tenants)
- `utils/`: Reusable logic and API wrappers
